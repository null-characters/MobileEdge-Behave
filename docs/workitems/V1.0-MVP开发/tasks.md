## 任务编排原则

1. **优先级顺序**：P0 → P1 → P2
2. **依赖顺序**：有依赖的任务按依赖顺序执行，无依赖的任务可并行
3. **关键路径**：T-01 → T-02 → T-04 → T-05 → T-06 → T-09 → T-11（核心功能链路）
4. **保活优先**：T-10 尽早完成，确保后续测试环境稳定
